# 7 Days of Python

A hands-on Python practice repository focused on building programming fundamentals through practical, business-oriented problems.

This project is structured as a day-wise learning challenge. Instead of solving only theory-based exercises, each task applies Python concepts to scenarios such as billing, sales analysis, customer data cleaning, inventory management, and operational reporting.

> **Current progress:** Day 1 to Day 5 and one mini-project are available in this repository. Days 6 and 7 will be added as the challenge progresses.

## Project Goals

- Strengthen Python fundamentals through consistent practice.
- Improve logical thinking and problem-solving ability.
- Apply programming concepts to realistic business scenarios.
- Build confidence in writing readable, structured Python programs.
- Develop a foundation for further learning in data analysis and data science.

## Getting Started

### Prerequisites

- Python 3.x
- A code editor such as Visual Studio Code
- Basic familiarity with running Python scripts

### Run the exercises

1. Clone the repository:

   ```bash
   git clone https://github.com/xevrith/7_Days_of_Python.git
   ```

2. Open the project folder:

   ```bash
   cd 7_Days_of_Python
   ```

3. Navigate to any day folder and run a Python file:

   ```bash
   python Day_1/1_Electricity_Bill_Calculator.py
   ```

You can run each exercise independently. No external Python libraries are currently required for the listed scripts.

## How to Use This Repository

1. Follow the folders in numerical order.
2. Read each problem and try solving it independently.
3. Test your solution with different inputs and edge cases.
4. Review your logic and improve the readability of your code.
5. Apply the concepts in the mini-project.
